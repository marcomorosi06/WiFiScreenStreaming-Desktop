Turn your computer into a **wireless screen transmitter or receiver**.

This application allows you to send your PC's screen to any device on the same local network, or view the screen from another device. It is designed to work seamlessly with the Android version.

⚠️ **Note:** WiFi Screen Streaming is currently in **BETA**. Features may be incomplete or subject to change.

*Work in progress. Screenshots coming soon!*

# ✨ Key Features

- **Server & Client Modes**
  Use the app to **send (Server)** or **receive (Client)** your screen.
- **Low Latency**
  Designed for fast and responsive screen mirroring over the local network.
- **Modern Interface**
  A Material You interface built with Jetpack Compose for Desktop.

# 🛠️ Building from Source

Requires **JDK 17 or newer**.

```bash
git clone https://github.com/marcomorosi06/WiFiScreenStreaming-Desktop.git
cd WiFiScreenStreaming-Desktop
```

### Run for testing

```bash
./gradlew run
# Windows:
gradlew.bat run
```
